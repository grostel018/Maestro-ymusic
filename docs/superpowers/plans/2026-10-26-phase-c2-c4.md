# Phase C, C2–C4: video controls, output device, speed

**Status:** phase C done (2026-10-26). C5: review fixes landed; perf p9 measured Song mode at 4.72% CPU vs Video 5.01%. From roadmap §6.

Speed is per session, not saved: a restart at 0.8× would surprise. Keep pitch is saved
(`player.keepPitch`). The output device has a player-bar menu, not a settings-page entry.

## Probe result (C2's first choice)
YTM builds its `#movie_player` without YouTube's control bar: `.ytp-chrome-bottom`, the settings
menu and every `.ytp-*-button` are absent, not hidden. Re-enabling it is impossible, so C2 builds
its own bar on the player API, which does have everything: `getAvailableQualityLevels` (up to
`hd2160`), `setPlaybackQualityRange`, `getAvailablePlaybackRates`, the `captions` module options,
`toggleFullscreen`.

## Tasks
1. **C2a: controls logic** (`video-controls.logic.ts`, pure, unit-tested): the YouTube shortcut
   map, quality labels and ordering, speed steps (0.25–2 plus custom), time formatting.
2. **C2b: control bar** (`video-controls.renderer.ts`): an overlay at the bottom of the video in
   Video mode, shown on hover, hidden after 2.5 s idle. Play, time, speed, captions with
   language, quality (saved to `player.res`), loop (YTM's repeat-one), picture-in-picture,
   theater (video fills the window), fullscreen (the phase-1 HTML fullscreen path). Shortcuts are
   live only while the player has focus (after a click on the video, until a click elsewhere).
   Setting `player.videoControls` (default on) with migration. Bench `s23`.
3. **C3: output device** (`audio-output.*`): a device menu from `enumerateDevices`. Main allows
   the `media` permission only for the app's own pages and never asks for the microphone.
   `HTMLMediaElement.setSinkId` (the engine comes in D1), hot-plug updates, fallback to the
   default device with a toast. Setting `player.outputDevice`. Unit: fallback logic. Bench `s24`.
4. **C4: speed and keep-pitch**: the speed menu also in the player bar (works in Song mode),
   `player.speed` and `player.keepPitch` (maps to `preservesPitch`), re-applied on every track.
   Bench `s25`.
5. **C5: phase review**: `pnpm t:full`, `pnpm t:perf` (audio-mode CPU, video-mode p95), one review.
